# Scout на лабораторном ПК

Scout показывает результаты nf-core/raredisease в браузере: SNV, SV, STR, MT и SMN, IGV по BAM, классификацию ACMG и комментарии.
Пайплайн при этом не меняется: Scout только читает архив `D:\data_annotated\...`.

## Что где лежит
| Что | Где |
|---|---|
| Отдельный Linux `scout` (MongoDB, Scout, справочники) | `D:\scout\wsl\ext4.vhdx`, только на D: |
| Данные прогонов | там же, где и были: `D:\data_annotated\<прогон>\` (ничего не копируется) |
| Скрипты | `C:\NGS_pipeline\Claude_folder\scout-setup\` |
| OMIM | берётся из `C:\NGS_interpretation_tool_vtopil\carrier_app\OMIM` и в интернет не уходит |

Linux пайплайна (Ubuntu на C:) установка не трогает. MongoDB ограничена 4 ГБ памяти, чтобы не мешать прогонам.

## Установка (один раз, ~1 час, лучше не во время замера пайплайна)
1. Откройте обычный PowerShell.
2. Выполните:
   ```
   powershell -ExecutionPolicy Bypass -File C:\NGS_pipeline\Claude_folder\scout-setup\install_scout.ps1
   ```
   Скрипт по очереди скачивает Ubuntu (~350 МБ), MongoDB и Scout (~300 МБ), гены Ensembl и Orphanet (~100 МБ).
   HGNC, HPO и gnomAD constraint уже лежат в комплекте.
3. В конце скрипт напишет «Scout работает: http://localhost:8000».

## Как пользоваться
- **Открыть Scout:** двойной щелчок по `SCOUT.bat`, адрес http://localhost:8000. Вход по адресу `admin@arcgen.local`, без пароля. Поэтому Scout открыт только на этом ПК.
- **Загрузить прогон** (после `ngs archive`):
  ```
  SCOUT.bat load 2026-10-22_SAMPLE03_M
  ```
  Кейс открывается с панелью OMIM-AUTO, то есть с вариантами в генах OMIM. Порог RankScore > 5. Варианты, патогенные по ClinVar, и все MT загружаются всегда.
- **Весь research-набор** (все гены): `SCOUT.bat research 2026-10-22_SAMPLE03_M`.
- **Повторная загрузка** того же прогона обновляет кейс. Решения и комментарии сохраняются.

## Важно
- Интерфейс Scout подгружает часть оформления из интернета (jsdelivr, jquery), поэтому браузеру нужен интернет.
- Для клинического набора генератор берёт `rank_and_filter/*_snv_ranked_clinical.vcf.gz`, а если его нет, то `clinical*/..._ranked_clinical*.vcf.gz`. Если нет ни того, ни другого, вместо него идёт research-файл с тем же порогом.
- У каждого VCF должен быть `.tbi`. Без индекса Scout молча загружает 0 вариантов, поэтому генератор это проверяет.

## Что можно добавить потом
- **loqusdb**: локальная база частот. Каждый загруженный образец пополняет якутскую частоту, и она видна прямо в Scout.
- Пароли и вход для коллег по локальной сети.
- Периодическое обновление OMIM, HPO и генов в базе Scout.
