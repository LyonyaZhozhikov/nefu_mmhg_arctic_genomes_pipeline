Scout в лаборатории

Как загрузить готовый прогон nf-core/raredisease в Scout и разбирать его в браузере: SNV, SV/CNV, повторы, митохондрии, SMN, IGV, классификация ACMG и комментарии. Пайплайн при этом не меняется: Scout только читает архив на D:.

Куда идут данные

1. Прогон в архивеD:\data_annotated\дата_КОД_пол\после ngs archive
2. ЗагрузкаSCOUT.bat load папкаварианты читаются в базу Scout
3. БазаD:\scout\wsl\отдельный Linux «scout» с MongoDB
4. Просмотрhttp://localhost:8000в браузере на этом ПК

Scout работает в своём Linux «scout», диск которого лежит на D:. Ubuntu пайплайна на C: он не трогает, а MongoDB ограничена 4 ГБ памяти, поэтому Scout можно держать открытым во время прогона. VCF и BAM не копируются: в базу попадают отобранные варианты, а BAM для IGV Scout читает прямо из папки на D:.

01Открыть Scout

  1. Запустите ярлык

    Двойной щелчок по C:\NGS_pipeline\Claude_folder\scout-setup\SCOUT.bat или адрес http://localhost:8000 в браузере.

  2. Войдите

    Введите адрес admin@arcgen.local и нажмите вход. Пароля нет, поэтому Scout открыт только на этом ПК и не виден из сети.

  3. Выберите кейс

    Институт nefu_mmhg_arcgen → список кейсов. Кейс называется по лабораторному коду, например SAMPLE01 (внутренний ID case_SAMPLE01).

Нужен интернет в браузере.

Оформление и скрипты страницы Scout (и сам просмотрщик igv.js) подгружает с публичных CDN (jsdelivr, jquery). Референс hg38 и дорожки IGV (гены RefSeq, MANE, ClinVar) лежат локально в «scout» после scripts/setup_igv_local.sh. Данные пациентов и файлы OMIM остаются на ПК.

02Загрузить прогон

В PowerShell или в окне «Выполнить» укажите имя папки прогона из D:\data_annotated:

C:\NGS_pipeline\Claude_folder\scout-setup\SCOUT.bat load 2026-10-23_SAMPLE01_F
  • Геном WGS загружается около 35 минут. Первые 3–5 минут уходят на чтение всего VCF (около 3 млн вариантов), потом идёт полоска с оставшимся временем. Окно не закрывайте.
  • В базу попадают варианты с RankScore выше 5, все митохондриальные варианты, SV и STR. Остальное доступно как research-набор (см. ниже).
  • В конце скрипт пишет адрес кейса: http://localhost:8000/nefu_mmhg_arcgen/case_КОД.
  • Повторная загрузка того же прогона обновляет кейс. Классификации, комментарии и отметки сохраняются.

04Разбор SNV и инделов

  1. Откройте клинические SNV

    Список отсортирован по RankScore: сверху варианты, которые модель ранжирования nf-core считает самыми вероятными. В списке: ген, HGVS, эффект, частоты gnomAD, CADD, модели наследования, ClinVar.

  2. Сузьте фильтром

    Слева фильтры: частота в gnomAD (например < 0,01), функциональный эффект (missense, frameshift, splice), CADD, ClinVar, панель генов или конкретные гены, регион. Кнопка Clinical filter ставит стандартный набор: редкие, белок-изменяющие, в генах панели.

  3. Откройте вариант

    На странице варианта: все транскрипты (MANE отмечен), предсказатели (SIFT, PolyPhen, REVEL, SpliceAI, CADD), консервативность, частоты, ClinVar, болезни OMIM для гена, качество вызова (глубина, доли аллелей).

  4. Посмотрите прочтения в IGV

    Кнопка IGV открывает встроенный просмотрщик прямо в браузере с BAM образца с D:. Проверьте, что вариант не артефакт: достаточно прочтений, обе цепи, не край прочтений.

Порог RankScore > 5.

Варианты с меньшим рангом в клинический список не попали. Если подозреваемого гена нет в списке, загрузите research-набор или посмотрите вариант в IGV по координате.

05Фенотип и список генов по HPO

Без фенотипа Scout показывает все гены OMIM. С фенотипом поиск сужается до генов, связанных с признаками пациента.

  1. Добавьте признаки

    На странице кейса в блоке Phenotype начните вводить по-английски (например seizures, intellectual disability) и выберите термин HPO. Можно вводить коды HP:0001250.

  2. Постройте список генов

    Scout соберёт динамический список генов по HPO. В фильтре SNV/SV выберите HPO gene list, чтобы смотреть только эти гены.

Для SAMPLE03 фенотип пока неизвестен, поэтому разбор по HPO для него станет возможен, когда появится описание пациента.

08Все команды

Команды с SCOUT.bat вводятся в PowerShell. Команды с wsl -d scout тоже в PowerShell: они выполняются внутри Linux «scout».

КомандаЧто делает
SCOUT.batоткрыть Scout в браузере
SCOUT.bat load ПАПКАзагрузить или обновить прогон из D:\data_annotated
SCOUT.bat research ПАПКАзагрузить все варианты во всех генах
wsl -d scout -u root bash /mnt/c/NGS_pipeline/Claude_folder/scout-setup/scout_load.sh listсписок кейсов в базе
wsl -d scout -u root systemctl restart mongod scout-webперезапустить Scout, если страница не открывается
wsl -d scout -u root journalctl -u scout-web -n 50последние ошибки веб-сервера (прислать Claude)
wsl -d scout -u root bash /mnt/c/NGS_pipeline/Claude_folder/scout-setup/scripts/setup_igv_local.shодин раз: скачать референс hg38 и дорожки IGV локально (~3,5 ГБ) и переключить IGV на них. Повторный запуск возвращает локальные дорожки, если их сбросили в настройках профиля
Страница не открывается
  • После перезагрузки ПК Linux «scout» стартует сам (ярлык scout_keepalive.vbs в автозагрузке Windows). Подождите минуту после входа в Windows.
  • Всё ещё нет: выполните команду перезапуска из таблицы, через 10 секунд обновите страницу.
  • Ошибка 500 на странице: пришлите Claude вывод journalctl из таблицы.
  • Не выполняйте wsl --shutdown во время прогона пайплайна: он остановит и Ubuntu с пайплайном.
